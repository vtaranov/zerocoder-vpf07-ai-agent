# VPf07 — AI-агент с инструментами

## Возможности

| Требование ДЗ          | Реализация                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| Интернет-поиск         | Встроенный OpenAI `web_search` в Responses API; ссылки на найденные источники                          |
| Погода в городе        | Open-Meteo: геокодирование → текущая температура, ощущаемая температура, условия, ветер, местное время |
| Курс криптовалют       | CoinGecko: ID монеты, валюта, цена и время обновления                                                  |
| Чтение и запись файлов | `file_read`, `file_write`: UTF-8, TXT/MD/JSON/CSV, до 100 000 байт                                     |
| История `memory.json`  | `data/memory.json`, отдельная история пользователей, сохранение после перезапуска                      |

В исходной формулировке ДЗ указан DuckDuckGo, но запросы к нему возвращали CAPTCHA, поэтому DuckDuckGo был заменен на OpenAI Web Search. 

## Модель и стоимость

Использование устаревшей версии gpt-5-mini вызвало некоторые сомнения, поэтому была проведена сверка цен различных моделей. В таблице указаны цены, действующие на 23.10.2026 по официальной странице OpenAI. Standard, USD за
1 миллион токенов:

| Модель | Вход | Кэшированный вход | Выход |
| --- | ---: | ---: | ---: |
| GPT-5 Mini (раньше в проекте) | 0.25 | 0.025 | 2.00 |
| GPT-5.4 nano | 0.20 | 0.02 | 1.25 |
| GPT-5.6 Luna | 0.20 | 0.02 | 1.20 |
| **GPT-6 Luna (выбрана)** | **0.10** | **0.01** | **0.50** |

У GPT-6 Luna вход дешевле на 60%, выход — на 75% относительно GPT-5 Mini.
Это сравнение тарифов за токены; итоговая стоимость зависит от их фактического
числа, рассуждений, кэширования и инструментов. Для GPT-6 Luna запись кэша
оплачивается отдельно по тарифу: 0.125 USD за миллион токенов для 30m-записи.

Сам Web Search стоит **0.01 USD за вызов**, плюс поисковый контекст и остальные
токены по тарифу модели. Один вопрос может вызвать несколько поисков.
В запросах явно выбран `service_tier=default` (Standard) и `reasoning.effort=low`.
Поиск доступен модели при необходимости, но не обязателен для каждого ответа.

Очевидным выбором стала модель luna.

## Запуск на macOS / Linux

Проверено с Python 3.13.15. Минимальная версия Python — 3.10.
Для блокировки одновременного запуска используется стандартный модуль `fcntl`.

Создание среды:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните `OPENAI_API_KEY` и `BOT_TOKEN`. `CHAT_MODEL=gpt-6-luna` по умолчанию.
Нужны доступ к модели и оплаченный баланс OpenAI. Open-Meteo и публичный
endpoint CoinGecko вызываются без дополнительных ключей.
`OPENAI_BASE_URL` по умолчанию — `https://api.openai.com/v1`.

Запуск бота для общения через Telegram:

```bash
.venv/bin/python bot.py
```

В чате Telegram отправьте `/start`, затем вопрос обычным языком.
Параметр `ALLOWED_USER_IDS` в `.env` ограничивает доступ списком ID через запятую.
Если список пуст, бот отвечает всем, кто пишет ему.

Команды: `/help`, `/files`, `/get имя.txt`, `/reset`.
Входящие текстовые файлы можно загрузить прямо в чат. Результат записи
скачивается через `/get`. `/reset` очищает свою историю; файлы сохраняются.
Превью ссылок отключены: внешняя карточка сайта может показывать данные
с другим временем обновления, чем ответ агента.

Запуск через терминал:

```bash
.venv/bin/python run.py
.venv/bin/python run.py --ask 'Найди официальную документацию Python asyncio'
```

Команды терминала: `/exit`, `/reset`, `/files`.
CLI и Telegram используют один JSON: запускайте один интерфейс за раз.
Повторный запуск блокируется файловой блокировкой.

## Примеры запросов

- «Найди официальную документацию Python asyncio, дай ссылки».
- «Найди документацию Open-Meteo и сохрани название и URL в sources.txt».
- «Какая сейчас погода в Токио, Япония?»
- «Сколько стоит Bitcoin в USD?» Затем: «А Ethereum в той же валюте?»
- «Создай notes.txt с планом изучения Python».
- «Прочитай notes.txt и сохрани краткое резюме в summary.txt».
- «Запомни: меня зовут Виктор». После перезапуска: «Как меня зовут?»

## Память и файлы

В `data/memory.json` сохраняются все успешные пары вопрос–ответ с временем UTC.
Каждый запрос получает последние 20 сообщений своей сессии. Запись JSON атомарна:
временный файл заменяет предыдущий после завершения записи. Повреждённая история
не перезаписывается автоматически. Незавершённый ответ в историю не добавляется.
Результаты инструментов передаются модели в текущем цикле; между запросами
сохраняется итоговый диалог.
Вопросы о том, что пользователь раньше говорил или просил запомнить, отвечаются
по истории диалога. После `/reset` сведения из файлов не подставляются вместо
забытого факта переписки. Отдельный запрос прочитать файл продолжает работать.

Файлы Telegram-пользователя находятся в `data/files/<user_id>/`, терминала —
в `data/files/cli/`. Абсолютные пути, переходы `..`, скрытые файлы и выход через
символические ссылки запрещены. Инструментов выполнения команд или произвольных
HTTP-запросов у агента нет.

Журнал `agent.log` содержит шаги, имена инструментов, статус поиска и типы ошибок,
без аргументов инструментов и текстов документов. Личные файлы, история, `.env`
и окружение исключены из ZIP и Git. Текст диалога и прочитанных файлов передаётся
в OpenAI для обработки. `store=False` отключает сохранение Responses для
последующего получения через API.

## Файлы проекта

- `agent.py` — цикл OpenAI, встроенный поиск и отображение ссылок.
- `tools.py` — погода, криптовалюты, чтение и запись файлов.
- `memory.py` — постоянная JSON-история.
- `bot.py`, `run.py` — Telegram и терминальный интерфейс.
- `config.py` — настройки, логирование, блокировка процесса.
- `test_agent.py`, `check_live.py` — автономные и реальные проверки.
- `build_submission.py` — ZIP по явному списку, проверка целостности и отсутствия ключей.
